## 서비스를 고른 기준

| 상황 | 선택 | 이유 |
|---|---|---|
| 트래픽이 적은 초기 서비스 | **Lightsail** | 월 정액으로 비용 예측이 쉽고 구성이 단순함 |
| 도메인 + HTTPS + 확장을 고려한 구조 | **EC2 + ALB + ACM + Route 53** | 인증서 자동 갱신, 로드밸런서 뒤에 서버를 숨길 수 있음 |
| 사용자가 늘어날 때 | **Lightsail 상위 플랜 + 관리형 DB · 버킷 · CDN** | 스냅샷으로 플랜 확장, DB 백업 · 정적 파일 분리 |

## 공통으로 지키는 것

- **필요한 포트만 연다.** DB · 캐시는 외부에 노출하지 않는다.
- **서비스 주소에는 고정 IP 또는 도메인을 쓴다.**
- **권한은 최소로 준다.** SSH 키, 토큰, 정책 모두 해당한다.
- **되돌릴 수 없는 작업은 문서로 영향 범위를 먼저 확인한다.**
- **비용 알림을 건다.** 지출 한도가 없는 계정은 Budgets로 대신 막는다.
